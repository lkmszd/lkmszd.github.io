# Егор Лукичев — QA-тестировщик

Лендинг-резюме: ручное тестирование мобильных и веб-приложений (iOS · Android · Web), 5 лет в VK Testers.
Без привязки к конкретной компании: ссылку можно отправлять в любую команду.

**Сайт:** https://lkmszd.github.io/

## Что внутри

- `index.html` — вся страница
- `assets/css/style.css` — стили (минимализм, светлая тема, тёмный блок контактов)
- `assets/js/main.js` — появление блоков при скролле, счётчики, копирование почты
- `assets/js/game.js` — мини-игра «Побег бага» (canvas, без библиотек)
- `assets/js/interactive.js` — имя реагирует на курсор, кольцо-курсор, магнитные кнопки, инверсия ч/б, режим QA «Найдите 5 багов»
- `assets/fonts/` — Inter Tight и JetBrains Mono (SIL OFL 1.1), урезаны до латиницы и кириллицы
- `assets/Lukichev_Egor_QA.pdf` — резюме в PDF
- `assets/og.png` — превью ссылки для Telegram и соцсетей

Сборки нет: это обычный статический сайт, его публикует GitHub Pages из ветки `main`.
